# Contributing

This repository is the public release surface of Auvryn's developer tools. Its contents are
exported, unchanged except for packaging, from Auvryn's development repository, so that what is
tested there is exactly what is published here.

- **Issues** are welcome here: bugs, documentation gaps, requests.
- **Pull requests** are welcome too. An accepted change is applied in the development repository
  and arrives here with the next export (you are credited in the commit).
- Every commit here records the development commit it was exported from (`EXPORT.json`).
